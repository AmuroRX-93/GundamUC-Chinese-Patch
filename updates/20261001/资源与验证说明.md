# 高达 UC：字幕细黑描边更新（2026-09-30）

这是离线校验通过、游戏内显示尚未验证的测试更新包，适用于 PS3 日版 BLJS10154 的指定汉化基线。不是完整游戏。

## 效果与范围

- 动态过场字幕增加约 1 个字库像素、90% 强度的黑边，保留白色文字主体。无需重新压制影片。
- 过场字幕与战斗通讯共用字库，所以战斗通讯也增加同样细边。同时补上菜单小字通道，覆盖静态剧情可能使用的菜单字库；共用菜单小字的其它界面也会带细边。
- 字体为思源黑体；CCM 映射、UV、字号度量、字距和页数逐字节保留。不改译文、字幕时间或视频素材。
- 战斗/过场小字处理 4,613 个文字字形，菜单小字新增处理 3,110 个文字字形；两套现有字库都保留原图标、空白和排版。字体仍统一为思源黑体，没有新增字库槽。BC3 压缩会量化抗锯齿灰度；不能称每个半透明边缘像素都不变。
- 本包包含此前的思源黑体与 HUD 缺字修复，不需要叠加安装上一份字体包。
- 已有的旧版“特殊战斗通讯与过场字体”独立备份没有删除或修改。

## 安装

1. 完整解压 ZIP，退出 RPCS3。
2. **无需安装 Python、联网下载依赖或配置 PATH。** Windows 10/11 64 位双击 `Windows安装.bat`；macOS（Apple 芯片或 Intel）双击 `macOS安装.command`。启动脚本自动调用对应包内环境。
3. 选择高达 UC 的游戏根目录（包含 `PS3_GAME`），确认安装。Windows 内嵌 Python 不含 Tkinter，会在黑色窗口提示“游戏目录：”，粘贴目录完整路径、回车，再输入 y 即可。Mac 若没有弹出目录窗口，也按该方式输入。

安装器自动识别以下三个精确基线：

- 2026.09.19 汉化正式版（内部版本字符串 `2026.09.19-delta.3-rc.1`）；
- 20260930 思源黑体/HUD 修复更新版；
- 刚才发出的20260930第一版过场描边包（含Python与不含Python的游戏资源相同）。

不支持原日文版、任意旧汉化版、其他修改版或直接修改 ISO。安装器校验三个资源文件的完整 SHA-256，遇到未知或混装版本会拒绝，不可绕过校验。重复安装会识别已更新，不重复追加数据。以后不要再用旧字体更新包覆盖本包。

Windows 手动只检查：`runtime\windows-x64\python.exe install.py --game "游戏目录" --check`

Windows 手动安装：`runtime\windows-x64\python.exe install.py --game "游戏目录" --install`

请保留 runtime 文件夹和其余包内文件，完整解压后运行，不在压缩软件内启动。本包 Windows 环境仅支持 x64，不支持 Windows 7 或32位系统。Mac 双击若被系统拦截，可在终端运行 `zsh macOS安装.command`；不要单独搬动启动文件。

准备过程中不会覆盖原文件，三个候选文件都校验成功后才提交；提交报错会回滚。若进程被强制结束，重新运行安装器可恢复事务。需要约 2 GB 临时空间，成功后自动清理事务文件，不长期复制整份游戏。

## 已检查与未检查

已检查：

- 重新解码封装后的全部 4,613 个目标字形，均非空、有深色边缘，原不透明白字核心保留；图标和空白保持一致。
- 相对于上一份思源黑体/HUD 候选，仅 `LAUNCHDATA.BND::80::4`、`GAMEDATA.BHD::80::4` 与 `GAMEDATA.BHD::635::4` 三份小字 TPF 内容改变。其他成员保持一致，两处字幕资源一致。
- 三个支持基线的真实资源在隔离临时目录安装成功，最终三个文件哈希匹配；重复安装不再追加。
- 三个基线在第 1/2/3 次提交后注入失败均回滚；未知或混装文件拒绝且不修改输入。
- 正式游戏和旧特殊字幕字库备份仍与原哈希一致。

限制：

- 本轮未启动游戏或模拟器，也未在 Windows 执行安装器。预览图使用实际重新解码字库，在模拟背景上合成，**不是游戏截图**，不代表已经在游戏内验收。静态剧情对比图已使用截图对应的真实背景素材；字幕合成位置为离线示例，不声称复现游戏相机/布局。
- 描边在原字符矩形内生成。战斗/过场小字 138 个、菜单小字 414 个字形有较明显笔画碰到矩形边缘，该边的描边会受裁切；没有为此扩张 UV 或改动文字尺寸，避免相邻字符污染和排版变化。完整字符清单见 `资源校验.json` 与 `静态剧情普查.json`。
- 尚未实测游戏字幕材质对 RGB/透明度的最终合成。若游戏中仍看不到黑边，需继续查渲染路径，不能仅凭离线预览认定已解决。
- 本包只修改游戏字库渲染的动态文字。若另有已经烧进视频画面的字幕，它不会被本包改动；这类文本需要原视频/字幕工程重新压制。

资源验证记录保留原构建日期；本次用户授权发布不代表增加了游戏内验收。

## 静态剧情专项普查

定位截图：0096巴纳吉第二段，资源 lsd96_01_01_02，背景 lsd96_01_01_02_c001；“偶然相遇的她说出的这句话——”来自独立 text.fmg 第4条，不是背景图内的文字。无需重新压制影片。

本体50段+DLC33段，共83段、932条非空字幕、1406个非空白字符。85个字幕布局记录除节点ID外样式字节完全相同。上述字符在战斗/过场小字与菜单小字两个入口都通过封装后非空与深色边缘检查，无新增缺字。完整资源清单及哈希见 静态剧情普查.json。

本轮没有证明FLO布局中每个数字字段的引擎含义，不能把末尾数值2直接当作font/02引用。为覆盖静态剧情的菜单渲染通道，本版同时给既有 menu_small 加边，不依靠此前未经证明的“所有过场均走 ingame_small”假设。共用菜单小字的界面也会有同样细边。最终是否正确显示黑边仍需游戏内验证；这是有明确资源范围的覆盖候选，不声称83段已逐段游戏验收。没有改动83段的图片、文本、布局和时间轴，也没有逐张对全部背景做OCR；不把本普查称为所有图片烧录文字已重绘。

## 内置 Python

Windows：官方 CPython 3.13.15 嵌入版 x64。Mac：python-build-standalone CPython 3.12.14，Apple/Intel 分别内置。来源指纹见 Python来源.json；运行环境许可随包保留，Mac 第三方许可见 Python第三方许可。Apple 芯片包内解释器启动和安装器只读入口检查通过；Windows/Intel Mac 解释器未在对应设备执行，原游戏运行验证状态不变。
