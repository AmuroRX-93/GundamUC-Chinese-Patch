## 2. 支持哪些已有汉化

安装器按完整文件 SHA-256 判断，不看文件夹名字：

| 当前游戏 | 怎么做 |
|---|---|
| 2026.09.19 汉化正式版，内部标识 delta.3-rc.1 | 直接用本包，一次更新 |
| 已装 20260930 思源黑体/HUD 更新 | 直接用本包 |
| 已装 20260930 第一版过场描边 | 直接用本包 |
| 已装静态剧情描边版或 20261001 启动修正版 | 游戏资源已是目标版本，重复运行不会追加 |
| 更早汉化、其他人改版、日文原版、其他地区、ISO | 不直接支持；不要绕过校验 |

更早汉化请先按仓库 9 月 19 日发行说明更新到对应基线。所谓“有汉化直接用”指以上登记版本，并不代表所有来源的汉化都能混装。

本包只修改本体 `PS3_GAME/USRDIR` 的 `LAUNCHDATA.BND`、`GAMEDATA.BHD`、`GAMEDATA.BDT`。不要选择 RPCS3 的 exe、`dev_hdd0` 或 DLC 目录。不会修改更新/DLC 安装、模拟器配置、存档或奖杯。

## 3. 开始前

1. 退出游戏和 RPCS3。先确保现有汉化可以正常启动。
2. **建议先备份上述三个文件**，方法见第 7 节；安装失败自动回滚不等于成功后仍保留永久备份。
3. 将 ZIP **完整解压**到可写目录。不能在压缩软件里直接运行，也不能只拷走 `.bat` / `.command` / `.py`。保留 `runtime`、`variants` 和所有同目录文件。
4. 游戏盘预留至少约 2 GB 临时空间；备份需要额外约 2 GB。安装器会按实际资源计算空间，不够就停止。

## 4. Windows 安装（Windows 10/11 x64）

双击 `Windows安装.bat` → 看到“游戏目录：”后粘贴包含 `PS3_GAME` 的游戏根目录 → 回车 → 输入 `y` → 回车。嵌入 Python 不带 Tkinter，使用文字输入是正常现象。游戏目录中有中文或空格可以保留。

例如游戏文件位于 `D:\Games\GundamUC\PS3_GAME\USRDIR`，就填写 `D:\Games\GundamUC`。也接受 `PS3_GAME` 或 `USRDIR` 目录。等待“安装完成”或“已经安装此版”，然后按键关闭。

- `Windows检查.bat`：只检查已有游戏是否匹配，不安装。
- `Windows校验安装包.bat`：核验包括 Python 在内的包内文件，不修改游戏。
- 日志自动写入安装包的 `logs`。退出码 0 表示正常结束；非 0 请看错误内容。

启动器直接调用包内 `runtime\windows-x64\python.exe`，不依赖系统 Python、PATH、pip 或在线下载。不支持 Windows 7、32 位系统；Windows ARM 未验证。

## 5. macOS 安装（Apple 芯片 / Intel）

双击 `macOS安装.command`，按提示选择或输入游戏目录，确认安装。脚本自动识别芯片并调用包内 Python。

- `macOS检查.command`：只检查游戏。
- `macOS校验安装包.command`：检查包内文件。
- 若 `.command` 没有执行权限，在安装包目录打开终端，运行 `zsh macOS安装.command`。若包内 Python 也丢失执行权限，优先用系统归档实用工具重新完整解压，保留 ZIP 内权限。
- 若系统拦截下载程序，确认来源为本仓库后按 macOS 的“隐私与安全性”提示允许本次运行；不需要全局关闭系统安全功能。

## 6. 常用命令

下面均在**解压后的安装包目录**执行，将游戏目录换成自己的。传 `--install` 会直接安装，不再询问 y；需要先检查就用 `--check`。所有命令都用包内 Python。

Windows PowerShell：

```powershell
# 检查安装包是否完整
& '.\runtime\windows-x64\python.exe' -I -S -B -X utf8 '.\run.py' --verify-package
# 检查游戏，不修改游戏
& '.\runtime\windows-x64\python.exe' -I -S -B -X utf8 '.\run.py' --game 'D:\Games\GundamUC' --check
# 自动安装到指定目录
& '.\runtime\windows-x64\python.exe' -I -S -B -X utf8 '.\run.py' --game 'D:\Games\GundamUC' --install
# 核对下载 ZIP（与发行页 SHA256SUMS.txt 对比）
Get-FileHash 'GundamUC_CN_Cumulative_Update_20261001_BLJS10154.zip' -Algorithm SHA256
```

macOS 终端（自动选择芯片）：

```sh
case "$(uname -m)" in
  arm64) UC_PY='./runtime/macos-arm64/python/bin/python3' ;;
  x86_64) UC_PY='./runtime/macos-x64/python/bin/python3' ;;
esac
"$UC_PY" -I -S -B -X utf8 ./run.py --verify-package
"$UC_PY" -I -S -B -X utf8 ./run.py --game '/你的游戏目录/GundamUC' --check
"$UC_PY" -I -S -B -X utf8 ./run.py --game '/你的游戏目录/GundamUC' --install
# 核对下载 ZIP
shasum -a 256 GundamUC_CN_Cumulative_Update_20261001_BLJS10154.zip
```

## 7. 备份、失败恢复与手动还原

**安装前**把 `PS3_GAME/USRDIR` 下上述三个文件一起复制到单独的新备份目录即可。不必复制整部游戏。这是游戏资源备份，不能代替存档备份；本包不读取或修改存档。

Windows PowerShell 备份示例（目标文件重名时停止）：

```powershell
$ucSource = 'D:\Games\GundamUC\PS3_GAME\USRDIR'
$ucBackup = 'D:\Backups\UC_更新前_20261001'
New-Item -ItemType Directory -Path $ucBackup -ErrorAction Stop
foreach ($ucName in @('LAUNCHDATA.BND','GAMEDATA.BHD','GAMEDATA.BDT')) {
  Copy-Item -LiteralPath (Join-Path $ucSource $ucName) -Destination (Join-Path $ucBackup $ucName) -ErrorAction Stop
  if ((Get-FileHash (Join-Path $ucSource $ucName)).Hash -ne (Get-FileHash (Join-Path $ucBackup $ucName)).Hash) { throw '备份校验失败' }
}
```

macOS 备份示例（目标目录已存在就停止）：

```sh
UC_SOURCE='/你的游戏目录/GundamUC/PS3_GAME/USRDIR'
UC_BACKUP='/你的备份目录/UC_更新前_20261001'
if mkdir "$UC_BACKUP"; then
  for UC_NAME in LAUNCHDATA.BND GAMEDATA.BHD GAMEDATA.BDT; do
    cp -p "$UC_SOURCE/$UC_NAME" "$UC_BACKUP/$UC_NAME" && cmp "$UC_SOURCE/$UC_NAME" "$UC_BACKUP/$UC_NAME" || break
  done
fi
```

需要退回时，先退出 RPCS3，再将同一次备份的**三个文件一起**复制回原来的 `USRDIR` 覆盖；完成前不要启动游戏。不要只还原其中一个。不要把不同日期或别的游戏的文件混用。安装成功后临时事务会清理，因此没有做备份就不能靠本包一键退回。

安装会先合成并校验全部候选，再提交；异常时自动回滚。若断电或强制终止导致 `.uc-outline-static-20260930-transaction` 残留，请保留它并重新运行安装入口恢复，不要手动删除。遇到恢复日志异常请保留现场并反馈。

## 8. 常见问题

- **还没问路径就退出 / No module named engine**：最新版已修复模块搜索路径。完整解压这一整包，不需要另盖小修复包。若提示缺文件，运行校验入口或重新解压；不是安装 pip 上的 engine。
- **runtime / Python 找不到**：解压不完整、只移动了入口，或文件被安全软件隔离；核对安全软件记录与发行 SHA256，不要盲目关闭防护。
- **资源版本不匹配 / unknown / 混装**：本体不属于已登记基线或曾被其他修改覆盖。停止安装，保留日志与当前文件；不要改哈希强装。确认是否先装了 9 月 19 日汉化。
- **检查显示 old / new / same**：分别是匹配的升级前资源、目标资源、该升级路线前后相同的资源；不是单凭“old”就报错。
- **扫描几秒或更久无变化**：会完整读取约 1.9 GB 的资源核对哈希，慢盘需要时间。不要重复开多个安装窗口。
- **有 RPCS3 进程 / 空间不足 / 权限不足**：退出模拟器、腾出游戏盘临时空间，确认游戏和补丁所在目录可写后重试。不要并行修改游戏。
- **已安装最新版**：正常，无需再装 HUD 或旧描边包。资源重复安装不会再次增长。
- **安装成功却仍看不清 / 缺字**：安装成功只证明文件合成与哈希匹配。冷启动游戏后确认实际加载的是刚修改的目录；反馈具体章节、画面和日志，不要清掉全部模拟器缓存或删存档。

反馈可附 `logs` 中对应日志、系统和 RPCS3 版本、游戏编号、具体画面。日志可能包含你的本地目录，公开提交前可遮去用户名等私人信息；不要发送完整游戏或个人存档。
