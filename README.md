# PS3《机动战士高达 UC》简体中文汉化补丁（BLJS-10154）

适用于 PS3 日版 **BLJS10154：光盘 APP_VER 01.00，及已核验的官方升级 APP_VER 01.01**，面向 RPCS3。

游戏编号 **BLJS-10154** 与 **BLJS10154** 指同一个日版游戏。本作也常称为“高达 UC”或“高达独角兽”，原名《機動戦士ガンダムUC》，英文名 Mobile Suit Gundam UC（Kidou Senshi Gundam UC）。本仓库提供这款 2012 年 PS3 游戏的简体中文汉化补丁与下载说明。

本项目提供剧情、任务通信、菜单、机体与人物名称、教程、章节及受支持 DLC 资源的中文差分补丁。需要你自己的匹配原版游戏及可选的已安装 DLC。不是游戏本体，也不会安装或解锁缺少的 DLC。

## 首次汉化安装（尚未安装本项目汉化时）

在 9 月 19 日发行页下载 `GundamUC_CN_Delta_20260919_rc1_BLJS10154.zip` 和校验文件。GitHub 的 **Code → Download ZIP** 仅包含说明与安装器源码，不含发行所需差分数据。

1. 准备可正常运行的已解密文件夹版游戏。此处的旧版首次汉化包需要 Python 3.10 或以上；上述 10 月 1 日累计更新包已内置 Python。
2. 完整解压发行包，退出 RPCS3。
3. Windows 打开 `安装或恢复.bat`；Mac 打开 `安装或恢复.command`；Linux 运行 `sh 安装或恢复.sh`。
4. 选择包含 `PS3_GAME` 的本体目录；如需 DLC 汉化，再选择 `dev_hdd0/game/BLJS10154`。
5. 等待安装完成，再启动游戏。安装器会先验证资源、保存回退，然后还原差分。

新版详细操作、Windows / macOS / Linux 命令、自定义目录、音频路径修复及备份恢复见 **[上一版如何更新／新版安装指南](docs/上一版如何更新_详细说明.md)**。影片汉化包含在差分内，无需另下 MP4 或视频补丁。

## 开发测试

在测试用的 Python 环境安装 `bsdiff4` 后，从仓库根目录运行：

```sh
python3 installer/test_installer.py
PYTHONPATH=installer python3 tests/test_delta.py
```

以上测试只操作临时模拟游戏文件，不读取真实游戏。Windows 可用 PowerShell 设置 `$env:PYTHONPATH = "installer"` 后运行第二项，Python 命令按本机安装调整。玩家安装补丁不需要执行测试或安装 bsdiff4。
