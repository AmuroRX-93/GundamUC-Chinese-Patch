# 机动战士高达 UC · 简体中文汉化补丁

适用于 PS3 日版 **BLJS10154 / APP_VER 01.00**，面向 RPCS3。

本项目提供剧情、任务通信、菜单、机体与人物名称、教程、章节及受支持 DLC 资源的中文差分补丁。需要你自己的匹配原版游戏及可选的已安装 DLC。不是游戏本体，也不会安装或解锁缺少的 DLC。

> **作者声明：仅限个人非商业使用；可免费分享本仓库链接，禁止二次传播补丁文件。请认准 AmuroRX-93。**

## 下载与安装

在右侧 **Releases** 下载完整的 `GundamUC_CN_Delta_20260914_BLJS10154.zip` 和校验文件。GitHub 的 **Code → Download ZIP** 仅包含说明与安装器源码，不含发行所需差分数据。

1. 准备可正常运行的已解密文件夹版游戏，以及 Python 3.10 或以上。
2. 完整解压发行包，退出 RPCS3。
3. Windows 打开 `安装或恢复.bat`；Mac 打开 `安装或恢复.command`；Linux 运行 `sh 安装或恢复.sh`。
4. 选择包含 `PS3_GAME` 的本体目录；如需 DLC 汉化，再选择 `dev_hdd0/game/BLJS10154`。
5. 等待安装完成，再启动游戏。安装器会先验证资源、保存回退，然后还原差分。

详细操作、Windows / macOS / Linux / Steam Deck 命令、自定义目录、备份恢复和报错处理见 **[安装与排错指南](docs/安装与排错.md)**。

## 适配范围

- 本体 114 个目标资源；DLC 349 个目标资源、49 个已登记内容索引。
- 部分受支持 DLC 可单独存在；缺少依赖或出现未知版本时拒绝写入。
- 不兼容任意修改版、其他地区版或未登记更新，不承诺 PS3 实机兼容。
- 已在 Apple 芯片 Mac / RPCS3 上确认中文画面；Windows、Linux 和 Steam Deck 尚未实机验证。未逐关游玩全部剧情与 DLC。
- 当前中文字形统一为黑体；对白仿原版细斜字体的改进尚未制作。不同界面的字号与排版效果可以不同。
- 专有缩写、型号、部分装饰英文、工作人员真实姓名及必要版权署名保留。

## 开发测试

在测试用的 Python 环境安装 `bsdiff4` 后，从仓库根目录运行：

```sh
python3 installer/test_installer.py
PYTHONPATH=installer python3 tests/test_delta.py
```

以上测试只操作临时模拟游戏文件，不读取真实游戏。Windows 可用 PowerShell 设置 `$env:PYTHONPATH = "installer"` 后运行第二项，Python 命令按本机安装调整。玩家安装补丁不需要执行测试或安装 bsdiff4。
