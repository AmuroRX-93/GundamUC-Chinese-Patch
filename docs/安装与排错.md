# 高达 UC 汉化补丁：跨平台安装与排错指南

适用发行版：`GundamUC_CN_Delta_20260914_r2_BLJS10154.zip`，2026 年 9 月 14 日。

这份指南对应 2026.09.14-delta.2 差分发行版及其 `install.py`。安装必须使用清单匹配的原始游戏资源；已安装本版相同结果的资源会跳过。旧版或不同资源须先恢复到受支持的原始版本。

## 1. 先确认能不能用

| 项目 | 要求或验证范围 |
| --- | --- |
| 游戏 | PS3 日版《机动战士高达 UC》，编号 **BLJS10154** |
| 游戏版本 | `PARAM.SFO` 的 `APP_VER` 为 **01.00**，具体资源还须通过安装器校验 |
| 文件形式 | 已解密、可正常运行的文件夹版，包含 `PS3_GAME` |
| 模拟器 | 本补丁面向 RPCS3；不是在“游戏补丁管理器”中导入的 YAML 补丁 |
| 安装器 | Python **3.10 或以上**，只使用自带模块，不需要 pip 安装依赖 |
| macOS | 已在 Apple 芯片 Mac 的 RPCS3 上确认中文游戏画面；未逐关验证全部内容 |

**不是所有名为“日版 1.00”的资源都完全一样。** 修改版、混合更新版、其他汉化版可能被拒绝；这是文件校验结果，不能靠改游戏编号解决。

本包不处理加密 ISO，不含游戏可执行文件、DLC 安装包、授权文件或密钥。只有 ISO 时，请先按 [RPCS3 官方入门指南](https://rpcs3.net/quickstart) 准备可正常运行的游戏文件，再安装汉化。直接解压加密 ISO 不等于完成解密。

## 2. 最简安装流程

1. 先确认未打本补丁的游戏能正常启动；已有能玩的同版汉化不必为测试而卸载。
2. 完整解压补丁 ZIP。保留 `install.py`、`manifest.json`、校验文件和全部资源目录的相对位置；不要在压缩软件预览窗口中运行。
3. 检查 Python 版本。关闭 RPCS3，包括后台仍在运行的窗口进程。
4. 打开对应入口，选择 **1 安装汉化**：Windows 使用 `.bat`，Mac 使用 `.command`，Linux 使用 `.sh`。
5. 选择包含 `PS3_GAME` 的**游戏文件夹**。安装器也接受选择其中的 `PS3_GAME` 或其 `USRDIR`。
6. 没有 DLC 就直接回车；要汉化已装 DLC，输入 `y`，选当前 RPCS3 使用的 `dev_hdd0/game/BLJS10154`。
7. 等待“安装完成”，再启动同一个游戏目录。不要中途拔盘、移动文件或强制关机。

不确定目录或版本时先选 **2 只检查、不安装**。检查会读取较多资源，机械硬盘、U 盘或云盘目录可能较慢；检查期间没有修改游戏。

解压之后建议再预留至少 **6 GiB** 空间，供临时生成和回退使用；最终以安装器按所选资源计算的空间要求为准。本体、DLC 位于不同磁盘时，两边都要可写且有空间。

## 3. 分清本体目录和 DLC 目录

本体示例：

```text
GundamUC/                    ← --game 选这里
└── PS3_GAME/
    ├── PARAM.SFO
    └── USRDIR/
        ├── EBOOT.BIN
        ├── LAUNCHDATA.BND
        ├── GAMEDATA.BHD
        └── GAMEDATA.BDT
```

DLC 示例：

```text
RPCS3 数据目录/
└── dev_hdd0/game/BLJS10154/   ← --dlc 选这里
    ├── PARAM.SFO
    └── USRDIR/
```

**DLC 不选下载文件夹，不选某个 PKG，也不选 `USRDIR` 本身。** 不要手工把两个 `USRDIR` 混在一起。

下列位置只是寻找起点。便携配置、自定义虚拟硬盘、环境变量和前端管理工具可以改变实际路径。

| 环境 | 常见寻找位置 |
| --- | --- |
| Windows 常见解压安装 | `rpcs3.exe` 所在目录下的 `dev_hdd0/game/BLJS10154` |
| macOS 常见配置 | `~/Library/Application Support/rpcs3/dev_hdd0/game/BLJS10154` |
| Linux 常见配置 | `~/.config/rpcs3/dev_hdd0/game/BLJS10154` |
| Linux Flatpak 常见配置 | `~/.var/app/net.rpcs3.RPCS3/config/rpcs3/dev_hdd0/game/BLJS10154` |
| Steam Deck、EmuDeck、自定义硬盘 | 以正在使用的 RPCS3 实际配置为准，可能在 Emulation 目录或其他盘 |

最可靠的方式是从**当前正在用的 RPCS3**确认：游戏列表右键查找“打开安装文件夹”等入口；再在菜单中查找虚拟文件系统（Virtual File System）设置，确认 `/dev_hdd0/` 指向哪里。版本不同，菜单名称和位置可能不同。找到后关闭模拟器再安装，不要为了套用示例而改虚拟硬盘位置。

Mac 的 Finder 可用“前往文件夹”输入上述 `~/Library/...` 路径；Linux 文件管理器通常可用 Ctrl+H 显示隐藏文件夹。看到同名的多个目录时，不要凭日期猜测，先核对模拟器启动的游戏位置。

## 4. Windows：图形入口与 PowerShell

从 [Python 官网](https://www.python.org/downloads/windows/) 安装适合电脑的 Python。不同安装方式可能提供 `py`、`python` 或两者；先查看版本，必须至少为 3.10。安装方式说明见 [Python 官方 Windows 文档](https://docs.python.org/3/using/windows.html)。

### 图形入口

完整解压后双击 `安装或恢复.bat`，依提示操作。窗口一闪而过时，用下面的终端方式查看具体错误，不必先用管理员身份运行。

### PowerShell 命令

以下路径均为示例，替换成自己的真实路径。每次只选需要的一条安装命令执行。

```powershell
# 进入含 install.py 的补丁目录
Set-Location -LiteralPath 'D:\Patches\GundamUC_CN_Delta_20260914_r2_BLJS10154'
py -3 --version

# 只检查本体，不写入
py -3 .\install.py --game 'D:\Games\GundamUC' --check-only

# 只安装本体
py -3 .\install.py --game 'D:\Games\GundamUC'

# 本体与已经安装的 DLC 一起检查
py -3 .\install.py --game 'D:\Games\GundamUC' --dlc 'D:\Emulators\RPCS3\dev_hdd0\game\BLJS10154' --check-only

# 本体与已经安装的 DLC 一起安装
py -3 .\install.py --game 'D:\Games\GundamUC' --dlc 'D:\Emulators\RPCS3\dev_hdd0\game\BLJS10154'
```

如果提示找不到 `py`，执行 `python --version`；确认版本合格后，把命令中的 `py -3` 换成 `python`。如果 `python` 只打开应用商店而没有显示版本，说明命令尚未指向可用解释器，可重新检查 Python 安装，或用其完整路径：

```powershell
& 'C:\实际的Python安装目录\python.exe' .\install.py --game 'D:\Games\GundamUC' --check-only
```

不要将汉化包放到 RPCS3 的 `patches` 文件夹再等待自动生效。安装目标是游戏资源，不是模拟器程序本身。

## 5. macOS：Apple 芯片与 Intel

两种 Mac 使用相同补丁和安装命令，但必须分别满足所用 RPCS3 构建的系统、处理器和显卡要求。Apple 芯片上的验证结果不代表 Intel Mac 也已经实测。

先运行 `python3 --version`。缺少合适版本时，可使用 [Python 官网 macOS 安装包](https://www.python.org/downloads/macos/)；安装细节见 [Python 官方 macOS 文档](https://docs.python.org/3/using/mac.html)。不要求安装 Xcode 或翻译开发工具。

双击 `安装或恢复.command` 可进入交互安装。若因执行权限无法打开，可以直接用终端运行 `python3 install.py`，不需要关闭系统安全功能。

```sh
cd "$HOME/Downloads/GundamUC_CN_Delta_20260914_r2_BLJS10154"
python3 --version

# 交互菜单
python3 install.py

# 只读检查，游戏放在哪里就填哪里
python3 install.py --game "$HOME/Games/GundamUC" --check-only

# 安装本体与已装 DLC；DLC 路径为常见默认值
python3 install.py --game "$HOME/Games/GundamUC" --dlc "$HOME/Library/Application Support/rpcs3/dev_hdd0/game/BLJS10154"
```

需要运行 `.command` 但只缺执行权限时，可在补丁目录运行：

```sh
chmod u+x './安装或恢复.command'
./安装或恢复.command
```

路径带空格必须加引号。终端中应写 `"$HOME/Games/..."`，不要写 `"~/Games/..."`；后者的波浪号通常不会被 shell 展开。

Mac 提示文件夹访问权限时，只授权实际使用的文件夹。遇到只读磁盘或无法写入的 Windows 格式分区，先把游戏放到自己可写的磁盘位置，不要用 `sudo` 强制覆盖。

## 6. Linux：普通版、AppImage 与 Flatpak

先检查系统 Python：

```sh
python3 --version
```

低于 3.10 时，使用发行版提供的合适 Python，或其正式支持的升级方式；不要覆盖系统 Python 以免影响系统工具。没有 Tk 文件选择器也可以使用完整命令行，安装器无需额外 Python 模块。

```sh
cd "$HOME/Downloads/GundamUC_CN_Delta_20260914_r2_BLJS10154"

# 交互菜单；无需给脚本执行权限
sh './安装或恢复.sh'

# 常见普通版目录：先检查
python3 install.py --game "$HOME/Games/GundamUC" --dlc "$HOME/.config/rpcs3/dev_hdd0/game/BLJS10154" --check-only

# 检查通过且退出 RPCS3 后安装
python3 install.py --game "$HOME/Games/GundamUC" --dlc "$HOME/.config/rpcs3/dev_hdd0/game/BLJS10154"
```

AppImage 是模拟器的启动形式，本补丁不用塞进 AppImage。先确认它实际使用的游戏和数据目录，再按上面处理。

使用 Flatpak 时，可先确认安装的应用：

```sh
flatpak info net.rpcs3.RPCS3
```

如果数据确实位于常见 Flatpak 目录：

```sh
python3 install.py --game "$HOME/Games/GundamUC" --dlc "$HOME/.var/app/net.rpcs3.RPCS3/config/rpcs3/dev_hdd0/game/BLJS10154" --check-only
python3 install.py --game "$HOME/Games/GundamUC" --dlc "$HOME/.var/app/net.rpcs3.RPCS3/config/rpcs3/dev_hdd0/game/BLJS10154"
```

安装器在主机终端运行。Flatpak 能否访问外置盘是模拟器的文件访问问题，与补丁校验是否通过是两回事；仅为实际游戏目录配置必要的访问权限。参见 [Flatpak 文件访问说明](https://docs.flatpak.org/en/latest/sandbox-permissions.html) 与 [RPCS3 的 Flathub 打包项目](https://github.com/flathub/net.rpcs3.RPCS3)。

## 7. Steam Deck、EmuDeck 与其他前端

1. 切换桌面模式，退出正在运行的游戏和 RPCS3。
2. 打开实际使用的 RPCS3，确认游戏文件夹及 `/dev_hdd0/` 路径，随后退出。
3. 在桌面终端检查 `python3 --version`，按上面的 Linux 命令运行安装器。
4. 游戏在 SD 卡时，把 `--game` 换成文件管理器显示的实际绝对路径；不要照抄别人的卡名。
5. 安装完成后，通过原有前端启动，确认该快捷方式没有指向另一份游戏。

这不是 Deck 专用补丁，也没有 Deck 帧率保证。如果系统没有 Python 3.10+，可在另一台支持的电脑上处理资源，再把更新后的本体及对应 DLC 文件放回原位置；应同时保留完整安装备份。不要为了安装补丁关闭 SteamOS 只读保护、覆盖系统软件或改动存档。

跨电脑处理时，需搬运本次修改的**本体和 DLC 两边资源**。仅搬本体不会更新另一台电脑的 DLC；原电脑备份记录中的绝对路径也不会自动成为新电脑的路径，恢复时见下一节。Linux 区分文件名大小写，请保留目录与文件原名。

前端名称、便携模式或自定义目录不会改变本补丁的输入条件：最终仍须提供正确的本体目录，以及可选的 DLC 目录。

## 8. 没有 DLC、部分 DLC、后来新增 DLC

| 情况 | 操作 |
| --- | --- |
| 完全没有 DLC | 不传 `--dlc`；交互模式在 DLC 提问处直接回车 |
| 只装了一部分受支持 DLC | 选择实际 DLC 目录；安装器只处理已存在的资源，并检查依赖完整性 |
| 以后新增或重新安装 DLC | 安装 DLC 后关闭 RPCS3，再同时指定本体与 DLC 重跑本补丁 |
| 已经是本版中文资源 | 安装器识别后跳过，不反复叠加 |
| DLC 编号或资源不匹配 | 停止安装并核对来源版本；不要改名、删除索引来骗过检查 |
| 更新包含新的 EBOOT 或本体主资源 | 当前版不承诺兼容，安装器可能拒绝该数据目录 |

本包适配 49 个已登记内容索引。**这不是“历史上全部 DLC 都已确认齐全”的声明，也不代表安装补丁会获得 49 个 DLC。** 汉化不负责购买、授权、解锁、存档进度或鉴赏内容开放。

本体字体与 DLC 中文配套使用。不要只挑几个 DLC 文件手工覆盖，更不要把任务的 BHD 与 BDT 拆开处理。

## 9. 恢复、迁移和安装中断

每次实际更新都会在游戏文件夹中建立：

```text
GundamUC_CN_Backups/日期时间编号/restore.json
```

保留该次备份文件夹的全部内容。恢复的是**这一笔安装之前的状态**，不必然是出厂日文状态。不要把不同日期的备份混合。

交互入口选择 **3 恢复安装前资源**，选含 `restore.json` 的具体文件夹。命令行示例：

```powershell
# Windows：替换“实际备份编号”
py -3 .\install.py --restore 'D:\Games\GundamUC\GundamUC_CN_Backups\实际备份编号'
```

```sh
# macOS / Linux
python3 install.py --restore "$HOME/Games/GundamUC/GundamUC_CN_Backups/实际备份编号"
```

游戏或 DLC 搬家之后，显式指定新位置：

```sh
python3 install.py --restore '/新位置/GundamUC/GundamUC_CN_Backups/实际备份编号' --game '/新位置/GundamUC' --dlc '/新的数据目录/dev_hdd0/game/BLJS10154'
```

本次备份没有 DLC 时省略 `--dlc`。Windows 将 `python3` 替换为自己可用的 Python 命令，并填写 Windows 路径。

普通写入失败会尝试自动回退。断电或强制结束后，可能留下 `.gundam-uc-cn.lock` 和临时目录：**先用对应备份恢复，不要直接删锁重装。** 如果程序在建立备份前就失败，或恢复也报错，请保存错误全文及事务目录，排查后再处理。

如果后来又装了其他补丁或 DLC，恢复校验可能拒绝覆盖变动文件；不要强行绕过。安装器不修改存档，但“重新复制整个模拟器目录”可能影响存档，勿将两件事混为一谈。

## 10. 常见错误与排查顺序

| 现象或提示 | 处理方式 |
| --- | --- |
| `can't open file ... install.py` | 终端没有进入正确目录；确认该文件存在，再切换目录 |
| 找不到 Python 命令 | 检查版本与安装位置；Windows 可试 `py -3` 或 `python`，Mac/Linux 用 `python3` |
| 缺少 `manifest.json`、补丁文件损坏 | 重新完整解压并核对 ZIP 校验值；不要只复制脚本 |
| 找不到 `PS3_GAME/PARAM.SFO` | `--game` 选错目录、仍是 ISO，或游戏文件不完整 |
| 游戏版本不符、原版资源不匹配 | 核对编号、APP_VER、解密状态、旧汉化和更新；不要修改清单放行 |
| DLC 缺少资源、任务资源不成对 | 修复对应 DLC 安装后重新检查；不要自行造空文件 |
| 检测到 RPCS3 运行 | 完整退出所有 RPCS3 实例；只关闭游戏画面可能不够 |
| 权限不足、只读文件系统 | 改用自己可写的目录，检查磁盘挂载和系统文件访问授权；勿使用全盘 `chmod 777` |
| 空间不足 | 为游戏和 DLC 所在盘腾出空间；不要删正在使用的回退或临时文件 |
| 只显示“检查通过” | 若命令带 `--check-only`，这是预期；去掉该参数才安装 |
| 装完仍显示日文 | 先确认已重启游戏、启动目录正确、DLC 也已选择；记录具体页面再排查漏译 |
| 字体有差别 | 当前统一汉字字形，但字号及游戏内倾斜等排版可不同；对白仿原版细斜字体尚未制作 |
| 中文显示方框或资源报错 | 核对本体与 DLC 是否配套、是否手动挑文件覆盖；先检查，不盲目替换字体 |
| PPU 编译、着色器编译或运行慢 | 先让编译完成并确认模拟器运行情况；不要把删缓存作为汉化安装的固定步骤 |
| 崩溃、黑屏 | 保存报错，必要时用本包备份恢复后对比；补丁成功校验不等于解决所有模拟器兼容问题 |

不同电脑的 RPCS3 性能设置不宜照搬。显卡、驱动、系统和 RPCS3 版本要求，请核对 [RPCS3 官方下载页](https://rpcs3.net/download) 与 [官方配置说明](https://wiki.rpcs3.net/index.php?title=Help:Configurations)。本文不固定可能过时的最低系统版本，也不要求为汉化而更新模拟器。

## 11. 校验下载与反馈

本指南对应的差分 ZIP 文件：`GundamUC_CN_Delta_20260914_r2_BLJS10154.zip`

SHA-256：

```text
请使用同一 Release 随附的 .sha256 文件中的 64 位值。
```

```powershell
# Windows PowerShell，在 ZIP 所在目录运行
Get-FileHash -LiteralPath '.\GundamUC_CN_Delta_20260914_r2_BLJS10154.zip' -Algorithm SHA256
```

```sh
# macOS，在 ZIP 所在目录运行
shasum -a 256 'GundamUC_CN_Delta_20260914_r2_BLJS10154.zip'
```

```sh
# Linux，在 ZIP 所在目录运行
sha256sum 'GundamUC_CN_Delta_20260914_r2_BLJS10154.zip'
```

与 Release 随附 .sha256 文件比较完整 64 位值，大小写无关。以后更新包、差分包或重新打包的 ZIP 必须使用各自的校验值；本值不能套用到它们。
