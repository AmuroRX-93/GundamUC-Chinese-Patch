# 高达 UC 汉化更新：1.00／1.01 兼容、影片字幕补充与字体优化

**正式发行更新｜构建编号：2026.09.19-delta.3-rc.1**

本次将已发布的 RC1 构建转为正式发行并设为最新版本，游戏资源、安装器和下载包均未变更。已下载 RC1 差分或对应整合版的用户无需重复下载、安装。为保持原链接、校验值及构建对应关系，保留 RC1 标签和文件名；包内原有“公开测试版”字样是制作阶段标记，实际验证边界以下文为准。正式发布不代表新增了此前未完成的实机验收。

本次更新面向 PS3 日版《机动战士高达 UC》（BLJS10154）。在上一版武器栏修正基础上，增加官方 01.01 升级及已核验 DLC 资源的兼容支持，补充部分影片对白字幕，优化字体和字幕触发，并提供旧版无 BGM／语音问题的音频路径修复工具。

## 新增与修正

- **兼容游戏 01.00／01.01**：保留原版光盘 01.00 支持，增加对本次已核验指纹的 01.01 升级程序及对应 DLC 资源的识别。口头所说的“1.0／1.1”在这里指 01.00／01.01。未知升级、其他地区版或混装修改资源不强行安装。
- **影片字幕补充**：加入序章拉普拉斯演讲 29 段字幕；为闪回的 12 句已有译文补入时间轴显示、切换及关闭事件；增加《台球作战》（帕劳作战）混音倒计时的 3 组字幕，并延长卡帝亚斯一处台词末字的显示时间。
- **字幕触发调整**：加宽 443 个字幕窗口控制事件，目标至少 12 个原生时间轴帧，并受相邻字幕及镜头边界约束。此数是控制事件数量，不是新增对白数；不改变已有对白文字的正常显示时间。目的是降低卡顿时漏触发的概率，尚不能宣称已完全消除漏字幕。
- **字体观感优化**：采用选定的仿原版衬线字形，相关汉化字形轻微加粗，改善过淡的观感；保留原字距、数字及图标。保留上一版武器栏专用小字库和武器名称修正。
- **音频路径修复**：附带按原始 UDF 路径核对大小写的工具，处理旧整合目录在区分大小写环境下可能出现的“音效有、BGM／人物语音没有”。不转码音频，也不把所有无声问题都归因于这一原因。
- **旧版直接更新**：安装器识别已登记的 `2026.09.14-delta.1` 和 `2026.09.14-delta.2` 资源，可在检查通过后更新，无需重新下载完整游戏。新增详细操作、校验、排错与恢复说明。

## 已有上一版怎么更新

1. 保存进度并完全退出 RPCS3，完整解压新版差分。
2. 准备自己的匹配本体；使用 01.01 的玩家须先安装自己持有的对应官方升级。不要手改版本号。
3. 先做只读检查。`--game` 指向包含 `PS3_GAME` 的目录；已安装升级或 DLC 时，`--dlc` 指向当前模拟器实际使用的 `dev_hdd0/game/BLJS10154`。
4. 检查通过后去掉 `--check-only` 安装。安装器保留回退副本；不要在运行中混合覆盖游戏资源。
5. 旧版若缺 BGM／语音，另运行包内音频路径工具，先检查再应用。

macOS／Linux 示例（替换为自己的真实路径）：

```sh
python3 ./install.py --game "/路径/GundamUC" --dlc "/实际RPCS3数据目录/dev_hdd0/game/BLJS10154" --check-only
python3 ./install.py --game "/路径/GundamUC" --dlc "/实际RPCS3数据目录/dev_hdd0/game/BLJS10154"
python3 ./tools/audio-paths/fix_audio_paths.py "/路径/GundamUC"
python3 ./tools/audio-paths/fix_audio_paths.py "/路径/GundamUC" --apply
```

Windows 将开头 `python3` 换成 `py -3`，并使用自己的 Windows 路径；也可运行 `安装或恢复.bat`。没有升级／DLC 时省略 `--dlc` 及其路径。

详细步骤见包内及仓库的 [上一版如何更新](https://github.com/AmuroRX-93/GundamUC-Chinese-Patch/blob/main/docs/上一版如何更新_详细说明.md)。版本检查失败时保留错误信息，不修改清单绕过校验，不删除整个 `dev_hdd0` 或个人存档。
